## Overview

Celery Executor PC is a Windows-focused Roblox script executor for users who need a simple desktop workflow for launching Lua scripts and organizing scripts through a large built-in hub. Its interface is designed to remain lightweight while providing quick access to everyday script-management tasks on current Windows systems.

Alongside direct execution, the application provides Roblox client update tracking, SQLite-backed queue persistence, and support for processing scripts in batches. A multilingual interface and embedded debugger round out the toolset for users who prefer a compact local application.
